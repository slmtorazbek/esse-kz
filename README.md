# esse.kz — бастапқы нұсқа

Бұл — esse.kz жобасының responsive веб-интерфейсі және PWA бастапқы қаңқасы.

## Файлдар
- `index.html` — бет құрылымы
- `styles.css` — дизайн және мобильді бейімдеу
- `app.js` — интерфейс әрекеттері
- `manifest.webmanifest`, `sw.js`, `icon.svg` — PWA және иконка

## Жергілікті тексеру
`index.html` файлын браузерде ашыңыз.

## Маңызды
Бұл нұсқада AI эссе генерациясы әлі қосылмаған. AI API кілтін браузердегі JavaScript файлына салмаңыз. Келесі кезеңде API кілтін серверлік функцияда сақтап, сұрауды сервер арқылы жібереміз. Сөз санын тексеру де сервер жағында және интерфейсте қайта тексерілуі керек.

## GitHub Pages
GitHub репозиторийіне файлдарды жүктеп, Settings → Pages → Deploy from a branch → `main` → `/ (root)` таңдаңыз.
